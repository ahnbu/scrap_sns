## Blocking Issues
1. **명령어 실행 불가 (PowerShell 전역 규칙 위반)**
   - 근거: 4.3절(`ls | sort | tail`), 4.4절(`grep -n`), 5절 W3-B / W3-C / W4의 스크립트 추출 명령(`F=$(ls ...)`, `cat`, `tr`, `wc -l`, `split -l 25` 등)
   - 실행 전 막히는 이유: 사용자의 전역 규칙인 `PowerShell 네이티브 구문으로 명령을 생성한다. Bash/CMD 전용 구문(grep, ls -la 등)을 그대로 사용하지 않는다`를 정면으로 위반했다. 현재 작성된 Bash 전용 구문들은 Windows 환경에서 실행 시 `CommandNotFoundException` 등으로 100% 실패한다. PowerShell 등가 명령(`Get-ChildItem`, `Select-String`, `Get-Content` 등)으로 모두 교체하거나, 명령이 복잡한 파일 분할(`split`) 등은 Node.js나 Python 스크립트로 분리해 실행하도록 해야 한다.

2. **명령 내 실행 불가 Placeholder (`<스크래치패드>`)**
   - 근거: 5절 W3-B, W4의 쉘 명령 (예: `> "<스크래치패드>/w3b_pilot_codes.txt"`) 및 4.5절 파일 경로 명시
   - 실행 전 막히는 이유: `<`와 `>` 문자는 Windows 경로에서 사용할 수 없는 특수문자이며, 터미널에서는 리다이렉션 연산자로 파싱되어 즉각적인 구문 오류와 실행 실패를 유발한다. 스크립트에 그대로 복사·붙여넣어 실행할 수 있도록 실제 쓰기 가능한 유효한 디렉토리 경로(예: `scratch/` 또는 `.scratch/`)로 교체해야 한다.
