## 2. 상황 (Situation)

### 2.1 사용자 제보 (2026-09-11)

1. 파일·웹 카드 「읽기」 팝업 가로가 너무 크다. 최대 폭을 지금의 절반쯤으로, 화면이 줄 때 비율로 줄이지는 말 것. 새 프로필 카드도 같다.
2. 프로필 카드 하단 여백이 없다 — 「다른 계정 연결」이 테두리에 닿는다.
3. 파일·웹 카드 본문에 줄바꿈이 없어 가로선 구분이 줄줄이 이어진다.
4. 파일·웹 카드 태그가 따로 붙어 있다 — 기존 태그와 통합 검토.
5. 파일 카드의 「공냥이」(스레드 공냥이와 같은 사람)를 누르면 공냥이 글 전체가 나와야 한다. ALL을 눌러도 안 나온다. 프로필을 누르면 자동으로 ALL로 바뀌고, 필요하면 채널 칩으로 교집합을 보는 편이 낫다.

사용자 확정(같은 세션): 태그는 A안(아래 §4), 읽기 팝업 최대 폭은 권장값(880px). 나머지는 권장안대로 진행하라는 지시로 계획문서 작성과 one-stop 실행을 받았다.

## 4. 검토한 옵션과 기각 근거

| 선택 | 채택 | 기각한 안 | 근거 |
|---|---|---|---|
| 누락 CSS 복구 방법 | `style.css`에 보강 규칙 추가 | Tailwind 재빌드 | 재빌드 명령·설정이 레포에 없다(F1). 재빌드는 동적으로 조합되는 클래스를 떨어뜨릴 위험이 있어 이번 범위에서 검증할 수 없다 |
| 모달 폭 지정 | 모달 패널에 의미 클래스(`library-note-panel`·`creator-card-panel`)를 달고 `style.css`에서 폭 지정 | `max-w-3xl`·`max-w-xl` 유틸리티를 보강 | 사용자가 정한 값(880px)이 Tailwind 단계값이 아니다. 유틸리티로 두면 다음 사람이 같은 함정에 빠진다 |
| 폭 방식 | 고정 최대폭 + `width:100%` | 화면 비율(예: 50vw) | 사용자 지시 — "화면이 반이 되었다고 절반 너비를 반으로 줄이지는 말 것" |
| `2xl:flex` | 보강하지 않고 검사 허용 목록에 사유와 함께 둔다 | 보강 | F18 — 정의하면 빈 열이 드러날 수 있다. 지금 화면이 의도대로 동작 중이다 |
