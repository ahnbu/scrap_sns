## 1. 상황 (Situation)

사용자가 뷰어를 사용하면서 3가지 이상 현상을 보고했다:
1. **X 선택 시 0건이 나온다.**
2. **My 게시글은 My 버튼을 누를 때만 보여야 하는데, All 등 다른 버튼을 눌러도 계속 나온다.**
3. **쓰레드 버튼을 누르면 내 게시글밖에 안 보인다 (반대로 동작하는 느낌).**

### 1.1 실측 데이터 현황
- 기준 통합 파일: `output_total/total_full_20260827.json` (총 2,554건)
  - **Threads**: 1,302건 (타인 수집글 1,270건 + 내 글 32건)
  - **LinkedIn**: 697건 (타인 수집글 661건 + 내 글 36건)
  - **YouTube**: 460건 (타인 수집글 460건 + 내 글 0건)
  - **X (Twitter)**: 95건 (타인 수집글 95건 + 내 글 0건)
  - **내 글(`is_own_post: true`) 총합**: 68건 (LinkedIn 36건 + Threads 32건)

## 2. 문제 (Complication)

### 2.1 P1 — `MY` 버튼이 배타적 탭이 아닌 독립 토글(AND 결합)로 동작하여 발생하는 연쇄 결함
`web_viewer/script.js`에서 `MY` 버튼은 플랫폼 칩(`filterContainer`)과 별개의 독립 토글 스위치(`showOwnPostsOnly`)로 구현되었고, `localStorage`에 상태가 영구 보존된다.

`getFilteredPosts()`의 필터 결합식:
```javascript
const matchesOwn = showOwnPostsOnly
    ? isOwnPost(post)
    : !(hideOwnPostsInAll && isOwnPost(post));
```

이로 인해 `MY` 버튼이 한 번이라도 활성화되면:
1. **X 클릭 시**: `currentFilter === 'x'` AND `is_own_post === true` → X에는 내 글 수집기가 없으므로 **0건 발생**.
2. **All 클릭 시**: `currentFilter === 'all'` AND `is_own_post === true` → 타인 글 2,486건이 차단되고 **내 글 68건만 노출**.
3. **Threads 클릭 시**: `currentFilter === 'threads'` AND `is_own_post === true` → 타인 쓰레드 1,270건이 차단되고 **내 쓰레드 32건만 노출** ("쓰레드 눌렀는데 내 글만 나온다").
4. **YouTube 클릭 시**: 동일하게 **0건 발생**.

### 2.2 P2 — 사용자 멘탈 모델과 UI 구현의 불일치
- **사용자의 기대 (멘탈 모델)**:
  `[All]`, `[★]`, `[LinkedIn]`, `[Threads]`, `[X]`, `[YouTube]`, `[MY]`는 같은 계열의 **상호 배타적 단일 탭**이다.
  `[Threads]`를 누르면 Threads 수집글(1,270건)을 보고, `[MY]`를 누르면 내가 쓴 글(68건)만 본다.
- **기존 설계의 오판**:
  "LinkedIn 중에서 내 글만 보기"를 위해 AND 토글로 설계하고 스토리지에 영구 저장했으나, 이는 탭 이동 시 상태가 고착되어 뷰어 전체 탐색 경험을 파괴함.

## 3. 해결 방안 (Resolution)

### 3.1 옵션 비교 및 권장안

| 옵션 | 내용 | 장점 | 단점 / 기각 근거 |
|---|---|---|---|
| **옵션 1 (권장)** | **`MY` 버튼을 플랫폼 칩과 동등한 1급 배타적 탭으로 단일화** | • 사용자 직관과 100% 일치<br>• 3가지 문제 일거에 해결<br>• 상태 관리 코드 및 설정 모달 토글 대폭 단순화 | • "LinkedIn 중 내 글" 단일 클릭 불가 (저자 필터나 검색으로 충분히 대체 가능) |
| **옵션 2** | `MY` 토글 유지 + 다른 탭 클릭 시 자동 리셋 (Auto-reset) | • 기존 UI 마크업 변경 최소화 | • 사실상 옵션 1과 동작이 같은데 버튼 UI만 분리되어 있어 시각적 불일치 지속 |
| **옵션 3** | `MY` 클릭 시 하위 플랫폼 서브 필터 바 노출 | • 다중 필터 기능 보존 | • 내 글이 총 68건에 불과한데 UI 구조만 불필요하게 복잡해짐 |

**권장안**: **옵션 1**. `MY`를 상단 필터 바의 단일 탭으로 편입한다.

### 3.2 상세 변경 계획

#### (1) `index.html` UI 마크업 정리
- `filterContainer` 내부의 플랫폼 칩 목록 마지막에 `<button data-filter="my" class="filter-chip flex items-center justify-center px-3.5 py-2 rounded-full bg-surface-glass hover:bg-surface-glass-hover text-gray-300 hover:text-white border border-border-glass transition-all whitespace-nowrap text-sm font-medium" title="내가 쓴 글 모아보기">MY</button>` 추가.
- 기존 독립 `#myPostsBtn` 요소 제거.
- 설정 모달 내 `tabDisplay` 탭 버튼 및 패널(`hideOwnPostsToggle` 포함) 제거/정리.

#### (2) `web_viewer/script.js` 필터링 및 상태 관리 단순화
- **레거시 상태 클린업**:
  `DOMContentLoaded` 초기화 루틴에서 과거 오동작 상태를 남길 수 있는 키 삭제:
  ```javascript
  localStorage.removeItem('sns_own_posts_only');
  localStorage.removeItem('sns_hide_own_posts');
  ```
- **필터링 조건식 단일화 (`getFilteredPosts()`)**:
  ```javascript
  const matchesFilter =
      currentFilter === 'all' ? true :
      currentFilter === 'favorites' ? isPostFavorited(post) :
      currentFilter === 'my' ? isOwnPost(post) :
      currentFilter === 'x' ? (post.sns_platform === 'twitter' || post.sns_platform === 'x') :
      (post.sns_platform || '').toLowerCase() === currentFilter;

  // 내 글 배타/포함 규칙:
  // - MY 탭: 내 글(is_own_post === true)만 노출
  // - Favorites 탭: 사용자가 별표한 글이면 내 글/타인 글 모두 허용
  // - All 및 플랫폼 탭: 내 글을 제외(!is_own_post)하고 일반 수집글만 표시
  const matchesOwn =
      currentFilter === 'my' ? isOwnPost(post) :
      currentFilter === 'favorites' ? true :
      !isOwnPost(post);
  ```
- **상단 모집단 건수 라벨 (`getPopulationTotal()`)**:
  - `currentFilter === 'my'`: 내 글 총건수(68건) 기준
  - `currentFilter === 'favorites'`: 전체 총건수(2,554건) 기준
  - `currentFilter !== 'my' && currentFilter !== 'favorites'`: 타인 글 총건수(2,486건) 기준
- 불필요해진 `showOwnPostsOnly`, `hideOwnPostsInAll` 변수 및 이벤트 핸들러 완전 제거.

#### (3) `tests/e2e/test_my_posts_filter_ui.py` E2E 테스트 개편
기존 독립 토글 및 설정 모달 토글 기반 테스트(V8~V10)를 단일 탭 전환 테스트로 개편:
- `test_my_tab_exists`: `button[data-filter="my"]` 칩 존재 및 초기 `All` 활성 상태 검증.
- `test_my_tab_shows_only_own_posts`: `MY` 탭 클릭 시 `is_own_post === true` 글(68건)만 노출 단언.
- `test_all_tab_excludes_own_posts`: `All` 탭 클릭 시 `is_own_post === true` 글 제외 및 일반 수집글(2,486건) 노출 단언.
- `test_threads_tab_shows_saved_threads_only`: `Threads` 탭 클릭 시 타인 글(1,270건) 노출 및 내 글 제외 단언.
- `test_x_tab_shows_all_x_posts`: `X` 탭 클릭 시 95건 정상 노출 단언.
- `test_favorites_tab_includes_favorited_own_posts`: 즐겨찾기한 내 글이 `Favorites` 탭에서 정상 노출되는지 단언.
- `test_tab_switch_flow`: `All` → `MY` → `Threads` → `X` 순차 클릭 시 각 탭에 맞는 정확한 건수와 카드 렌더링 확인.
